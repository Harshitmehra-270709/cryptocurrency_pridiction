# cryptocurrency_pridiction

Developed a predictive model for cryptocurrency prices using historical market data and machine learning techniques. The project involved data collection, preprocessing, feature engineering, and exploratory data analysis. Utilizing Python libraries such as Pandas, scikit-learn, and TensorFlow, I built and fine-tuned time series models to forecast price movements. Additionally, I visualized the trends and model outcomes using Seaborn and Matplotlib to provide clear, actionable insights for data-driven investment decisions.
